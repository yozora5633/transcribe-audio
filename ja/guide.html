2. 本アプリの位置づけ

1.　本アプリは，日本語の会話を録音し，又は音声ファイルを取り込んで，文字起こしを作成するツールである．

2.　文字起こしは，設定に応じて単独又は複数の音声認識エンジンと言語モデルを用いる機械処理の結果であり，誤りを含み得る．録音の状態，話し方，専門的な語彙その他の条件により，誤りの程度は変動する．

3.　正確さが求められる用途に用いる場合は，区間再生の機能により原音声と照合し，利用者自身が内容を確認されたい．確認を経た最終的な文章の内容は，利用者の判断に委ねられる．

3. 認識結果の性質

1.　話者の推定は，声の特徴及び発話の内容からの推定であり，取り違えが生じ得る．声紋認証のような本人の特定を行うものではない．

2.　補正候補として表示されるものは，別の読みの可能性の提示にすぎない．採否は利用者の操作による．

3.　辞書に登録した語句は認識の手がかりとして用いられるが，登録どおりの表記が常に得られることを保証するものではない．

4. 外部サービスの利用について

1.　本アプリの文字起こしは端末の中で行う．本アプリが OpenAI 等の外部の音声認識又は AI のサービス（以下「外部サービス」という．）を利用する機能を備える場合，その機能は，利用者が設定でその利用を選んだときに限り使用される．

2.　外部サービスの API キーを用いる機能は，利用者が外部サービスと自ら契約し，取得したキーを設定したうえで，利用の範囲と各機能を選ぶことにより使用できる．キーを保存するだけでは送信は始まらない．API の利用料は，利用者と外部サービスとの間で精算され，本アプリの代金とは別である．

3.　外部サービスへ送信されるデータについては，プライバシーポリシーの定めるところによる．送信を止めるには，設定で外部サービスの利用をやめるか，キーを削除すればよい．

4.　キーの管理は利用者の責任において行われたい．新たに保存するキーは端末の Keychain（暗号化領域）に保存し，外部サービスへの認証以外には使用しない．以前の版の設定領域に平文のキーが残っている場合は，外部サービスの機能の有効・無効にかかわらず，起動時に Keychain への移行を行う．Keychain に保存済みのキーがある場合はそれを優先し，旧設定領域のキーを削除する．移行のための保存に失敗した場合は旧設定領域の平文を残し，次回の起動時に再び移行を試みる．

5.　外部サービスの「接続テスト」は，モデルの一覧の取得と固定の短文の送信により利用の可否を確かめるものである．音声，文字起こしの本文及び辞書は送らない．少額の API の利用料が発生することがあり，残高の照会ではない．

6.　結果の画面のメニューから「作文ツールで整える」を選ぶと，元の文字起こしとは別の下書きを編集できる．対応する環境では OS の作文ツール及び ChatGPT を利用でき，整えた文章は別にコピー・保存する．この機能は本アプリの API キーを使わず，API の料金は発生しない．無料・未ログインでの利用には制限があり，利用の上限及び有料プランの条件は ChatGPT 側に従う．利用の可否と送信は OS 側の設定に従い，本アプリの外部サービスの設定とは別に扱われる．Apple の設定手順を参照されたい．
