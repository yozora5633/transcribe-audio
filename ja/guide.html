2. 本アプリの位置づけ

1.　本アプリは，日本語の会話を録音し，又は音声ファイルを取り込んで，文字起こしを作成するツールである．

2.　文字起こしは，複数の音声認識エンジンと言語モデルによる機械処理の結果であり，誤りを含み得る．録音の状態，話し方，専門的な語彙その他の条件により，誤りの程度は変動する．

3.　正確さが求められる用途に用いる場合は，区間再生の機能により原音声と照合し，利用者自身が内容を確認されたい．確認を経た最終的な文章の内容は，利用者の判断に委ねられる．

3. 認識結果の性質

1.　話者の推定は，声の特徴及び発話の内容からの推定であり，取り違えが生じ得る．声紋認証のような本人の特定を行うものではない．

2.　補正候補として表示されるものは，別の読みの可能性の提示にすぎない．採否は利用者の操作による．

3.　辞書に登録した語句は認識の手がかりとして用いられるが，登録どおりの表記が常に得られることを保証するものではない．

4. OpenAI API の利用について

1.　OpenAI の API キーを用いる機能は，利用者が OpenAI と自ら契約し，取得したキーを設定することで有効になる．API の利用料は，利用者と OpenAI との間で精算される．

2.　キーを設定している間に外部へ送信されるデータについては，プライバシーポリシーの定めるところによる．送信を止めるには，設定画面からキーを削除するか，「OpenAI の利用範囲」を「使わない」にすればよい（「文章だけ」は音声を送らず，文章・辞書登録語・声の数値特徴を照合等に用いる）．

3.　キーの管理は利用者の責任において行われたい．キーは端末の Keychain（暗号化領域）にのみ保存され，OpenAI への認証以外には使用されない．

2.　利用者が共有機能その他の操作により自らデータを端末外へ送出する場合は，前項の限りでない．

3.　データの削除の方法及び自動削除の設定については，プライバシーポリシーの定めるところによる．
