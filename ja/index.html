Transcribe Audio とは

Transcribe Audio は，面談・会議などの日本語の会話を録音し，文字起こしする iPhone / iPad アプリである．複数の音声認識エンジンの結果を突き合わせて確からしい文章にまとめ，話者の推定や，誤りやすい語の補正候補の提示を行う．

できること

その場で録音するか，音声ファイルを取り込むと，逐語の文字起こしが作られる．区間ごとに原音声を再生して聞き比べながら，本文を修正できる．

結果はテキストと Markdown で書き出せる．よく使う人名・用語は辞書に登録でき，認識の助けになる．

データの扱い

録音・文字起こし・履歴・辞書は，すべてあなたの端末の中に保存される．開発者のサーバーは存在せず，開発者が内容を受け取ることも見ることもない．

より精度の高い認識を使いたい場合は，あなた自身の OpenAI API キーを設定できる．このときに限り，音声や文字起こしが OpenAI へ送信される．キーを削除すれば外部への送信は完全に止まる．

会話を録音するときは，相手の同意と，所属先の規程に従うこと．
