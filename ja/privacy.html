Transcribe Audio プライバシーポリシー

最終更新日: 2026年9月11日

1. 基本方針

1.　本アプリは，利用者の個人情報を開発者へ自動送信しない．利用者が任意にメール又は不具合報告を送った場合は，開発者は送信元のメールアドレス，問い合わせ本文及び添付された動作の記録を受け取る．

2.　本アプリは，利用者の行動を追跡せず，広告識別子を利用せず，解析基盤を組み込んでいない．

3.　開発者は，本アプリのためのサーバーを有しない．録音・文字起こし・履歴・辞書は，すべて利用者の端末内に保存される．

4.　前3項にかかわらず，利用者が Apple との診断情報の共有を有効にしている場合，開発者は，Apple を通じて，個人を特定しない範囲の障害報告又は統計を受け取ることがある．これは Apple が収集するものであり，本アプリが収集するものではない．

2. 開発者が収集しない情報

本アプリは，次の情報を開発者へ自動送信しない．利用者からの任意の問い合わせ及びAppleからの診断情報は第1条のとおりである．

一　氏名，住所，電話番号，メールアドレスその他の連絡先

二　録音した音声及びその文字起こしの内容

三　辞書に登録した語句

四　利用者が設定した API キー

五　位置情報

六　広告識別子（IDFA）その他の端末識別子

七　利用状況の統計又は解析情報

3. 端末内に保存される情報

1.　本アプリは，次の各号に掲げる情報を利用者の端末内に保存する．

一　録音した音声及び取り込んだ音声ファイル

二　文字起こしの本文，履歴及び書き出したファイル

三　辞書に登録した語句

四　各種設定の内容

五　動作の記録（不具合の原因を確認するためのもの．音声及び文字起こしの内容を含まない）

2.　前項の情報のファイルには，iOS のファイル保護（ロック中の暗号化）を適用している．API キーは端末の Keychain（暗号化領域）にのみ保存される．Face ID 等によるアプリロックを設定することもできる．

3.　データ保存期間は，新規にインストールした場合は90日が既定となる．以前から利用している端末では既存の設定を保持し，移行時に今後作成するデータだけを90日で整理することも選べる．この移行時の選択によって，既存のデータが遡って削除されることはない．期間を過ぎた音声・書き出しファイル・履歴等は自動的に削除される．第1項の情報は，本アプリ内又はファイル App の操作により削除することができ，本アプリを端末から削除した場合，端末内のアプリのデータも併せて削除される．ただし，利用者が指定フォルダへコピー又は書き出したファイルは別管理となり，アプリの自動削除やアンインストールでは削除されない．

4.　開発者は，利用者の端末内の情報へ直接アクセスすることはできない．利用者が任意に送信した問い合わせ及び報告は第1条のとおりである．なお，利用者が端末のバックアップ機能を利用している場合，録音・文字起こし・履歴・辞書等の複製がバックアップ先に保存される（バックアップの有無・範囲は利用者の iOS の設定に従う）．ただし，異常終了レポート・取り込んだ音声の複製・ダウンロード済みの音声認識モデルは，端末固有又は再取得可能なデータであるため，バックアップから除外している．

4. 外部への送信が発生する場合

次の各号に掲げる場合に限り，端末の外への通信が発生する．

1.　利用者が自らの OpenAI API キーを設定し，利用範囲と個別の処理設定で送信を許可した場合，次のデータが OpenAI（api.openai.com）へ送信される．キーを保存する操作だけでは，送信の許可範囲は広がらない．

一　OpenAI による文字起こし又は音声による話者分けを使う場合の音声データ（分割したもの）．両方を併用すると，同じ区間の音声を各処理へ送信する．新世代モデルを使う場合は，辞書に登録した語句も認識の手がかりとして併せて送信される

二　OpenAI による録音中のライブ文字起こしを使う場合の録音中の音声．録音画面でオフにすると，この音声送信は止まる．対応する OS では端末内のライブ文字起こしを利用でき，非対応の OS では録音のみを保存する

三　文字起こし後の照合・話者の判定等における文字起こしの本文，辞書に登録した語句，及び声の高さ等の数値の特徴（音声そのものは送らない）

2.　前項の処理は，API キーの有無，OpenAI の利用範囲及び個別の処理設定に従って動作する．前項の API 処理による OpenAI への送信を止めるには，設定で「OpenAIへの送信を許可」をオフにするか API キーを削除すればよい．上級者向け設定の「文章だけ」は，音声を送らず，文章の照合・話者の再判定等に必要な本文・辞書登録語・声の数値特徴の送信を許可する．送信されたデータの取扱いは，OpenAI のプライバシーポリシー及び利用規約の定めるところによる．API キーは OpenAI への認証以外には使用されない．

3.　「iOS 標準」方式を選んだ場合，OS のバージョンや設定によっては，OS の音声認識機能が音声を Apple のサーバーで処理することがある．「完全オンデバイス」をオンにすると，端末内の処理に限定できる．

4.　次の各号に掲げる通信には，録音及び文字起こしの内容は含まれない．

一　同梱していないWhisper モデル・Tokenizerを利用者が準備する際のダウンロード（Hugging Face）

二　iOS 標準方式の音声認識アセットのダウンロード（Apple）

三　App Store での購入・復元の処理（OS の StoreKit が Apple と直接通信する）

四　利用者が実行する OpenAI の接続テスト．モデル一覧の取得と固定の短文による確認を行う．録音・文字起こしの本文・辞書は送らない．API の少額の利用料が発生することがある．OpenAIへの送信許可がオフの間は実行しない

5.　利用者が保存先又は共有相手に iCloud Drive 等のクラウドを自ら選んだ場合は，その選択先へデータが複製される．

6.　利用者が任意に OS の作文ツールを使用する場合，選択した機能に応じて，文章や入力した指示が Apple 又は ChatGPT（OpenAI）による処理のため端末外へ送信されることがある．この機能は本アプリの OpenAI API キーを使用せず，第2項の利用範囲の設定とは別に動作する．作文ツール及び ChatGPT の利用可否や送信時の確認は OS 側で管理され，送信された情報には利用するサービスのプライバシーポリシー及び利用条件が適用される．AppleのChatGPT拡張の説明も参照されたい．

5. 端末の機能の利用目的

本アプリは，次の各号に掲げる目的のために端末の機能を利用する．利用の可否は，利用者が端末の設定において変更することができる．

一　マイク　面談・会話の録音と，そのライブ文字起こしのため

二　音声認識　音声を文字に変換するため．設定によっては Apple のサーバーで処理されることがある

三　Face ID 等の生体認証　アプリロックのため．認証の情報は端末内で処理され，本アプリはこれを取得しない

四　通知　文字起こしの完了又は失敗を知らせるため

6. 第三者への提供

本アプリが開発者へ自動送信する利用者情報はなく，開発者による第三者への自動転送も行わない．第4条第1項の OpenAI への送信は，利用者が自ら API キーを設定して行う利用者の指示に基づくものである．

7. 広告

現在の配布ビルドに広告は含まれていない．将来，広告を導入する場合も，興味関心に基づかない配信（非パーソナライズ）のみを使用し，録音・文字起こしの内容や辞書に登録した語句を広告事業者へ送ることはない．

8. 言語

本方針は日本語を正文とする．他の言語に翻訳して提供する場合において，日本語版と他の言語版との間に相違があるときは，日本語版の解釈が優先する．

9. 本方針の変更

開発者は，本方針の内容を変更することがある．変更した場合は，本ページを更新し，最終更新日を改める．
