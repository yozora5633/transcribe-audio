KaiwaLog（旧名：Transcribe Audio） プライバシーポリシー

最終更新日: 2026年10月7日

1. 基本方針

1.　本方針は，KaiwaLog（以下「本アプリ」という．）における利用者の情報の取扱いを定める．本方針のうち特定の機能に関する定めは，その機能を備えた版において，利用者がその機能を利用する場合に適用される．

2.　本アプリの文字起こしは，利用者の端末の中で行う．録音した音声及び文字起こしの内容は，利用者が第4条第2項の外部サービスの利用を選んだ場合，及び利用者が共有，書き出し，作文ツール，不具合報告その他の操作により自ら送り出した場合を除き，端末の外へ送信されない．

3.　本アプリは，利用者の個人情報を開発者へ自動送信しない．利用者が任意にメール又は不具合報告を送った場合は，開発者は送信元のメールアドレス，問い合わせ本文及び利用者が添付を選んだ記録を受け取る．

4.　本アプリは，広告等を目的として利用者の行動を追跡せず，広告識別子を利用せず，解析基盤を組み込んでいない．不具合の原因を確認するための画面表示及び操作の記録は，第3条のとおり端末内に保存する．

5.　開発者は，録音，文字起こし，履歴及び辞書を受け取り，又は保存するためのサーバーを有しない．これらは，利用者の端末内に保存される．

6.　前各項にかかわらず，利用者が Apple との診断情報の共有を有効にしている場合，開発者は，Apple を通じて，個人を特定しない範囲の障害報告又は統計を受け取ることがある．これは Apple が収集するものであり，本アプリが収集するものではない．

2. 開発者が収集しない情報

本アプリは，次の情報を開発者へ自動送信しない．利用者からの任意の問い合わせ及び Apple からの診断情報は第1条のとおりである．

一　氏名，住所，電話番号，メールアドレスその他の連絡先

二　録音した音声及びその文字起こしの内容

三　辞書に登録した語句

四　利用者が設定した API キー

五　位置情報

六　広告識別子（IDFA）その他の端末識別子

七　利用状況の統計又は解析情報

八　支払い方法，カード番号その他の決済の情報

3. 端末内に保存される情報

1.　本アプリは，次の各号に掲げる情報を利用者の端末内に保存する．

一　録音した音声及び取り込んだ音声ファイル

二　文字起こしの本文，履歴及び書き出したファイル

三　辞書に登録した語句

四　各種設定の内容

五　動作の記録（不具合の原因を確認するため，画面の表示・非表示及び操作の種類を時刻とともに記録する．音声は含まない．文字起こしの詳しい記録には，認識した文が含まれることがある）

六　長い音声の文字起こしを続きから再開するための途中の結果及び進行状況（認識した本文を含む．第6項）

七　録音の途中のファイル（録音終了後に M4A へ変換するためのもの．第7項）

2.　前項の情報のファイルには iOS のファイル保護を適用し，暗号化された状態で保存する．録音中のファイルには，開いているファイルへの書き込みをロック中も続けられる種類の保護を用いる．動作の記録及び認識用に分割した一時音声には，端末の再起動後に一度ロックを解除すると，その後のロック中も読み書きできる種類の保護を用いる．第4条第2項の機能を備えた版で外部サービスへ音声を送る場合，送信用の一時ファイルにもこの保護を用いる．API キーを設定する機能を利用する場合，新たに保存する API キーは端末の Keychain（暗号化領域）に保存する．以前の版の設定領域に平文の API キーが残っている場合は，外部サービスの機能の有効・無効にかかわらず，起動時に Keychain への移行を行う．Keychain に保存済みのキーがある場合はそれを優先し，旧設定領域のキーを削除する．移行のための保存に失敗した場合は旧設定領域の平文を残し，次回の起動時に再び移行を試みる．Face ID 等によるアプリロックを設定することもできる．

3.　データの保存期間は，新規にインストールした場合は90日が既定となる．以前の版から利用している端末では既存の設定を保持し，今後作成するデータだけを90日で整理することも選べる．この選択によって，既存のデータが遡って削除されることはない．保存期間とその対象範囲に従い，期間を過ぎた音声・書き出したファイル・履歴等は自動的に削除される．以前の版からの利用では，録音が自動削除の対象外となる場合がある．対象範囲は設定画面に表示し，保存期間を短くして削除を承認するまで，対象外の録音は自動削除しない．取り込んだ音声の写し及び再開用の途中の結果には，第5項及び第6項の定めも適用する．動作の記録は，一定の期間又は量を超えたものから自動的に削除される．録音，文字起こし，履歴及び辞書は，本アプリ内又はファイル App の操作により削除することができ，本アプリを端末から削除した場合，端末内のアプリのデータも併せて削除される．ただし，利用者が指定したフォルダへコピー又は書き出したファイルは別に管理され，本アプリの自動削除やアンインストールでは削除されない．

4.　開発者は，利用者の端末内の情報へ直接アクセスすることはできない．利用者が任意に送信した問い合わせ及び報告は第1条のとおりである．なお，利用者が端末のバックアップ機能を利用している場合，録音・文字起こし・履歴・辞書等の複製がバックアップ先に保存される（バックアップの有無・範囲は利用者の iOS の設定に従う）．ただし，異常終了レポート，動作及び文字起こしの診断記録，取り込んだ音声の複製，再開用の途中の結果並びにダウンロードした音声認識モデルは，バックアップの対象外である．

5.　取り込んだ音声の写しは，履歴で使っている間は履歴とともに保持する．再開のためだけに残す写しは，最後の使用から24時間，48時間（既定）又は7日のうち設定で選んだ期間を過ぎると，自動削除の対象となる．この期間は第3項のデータの保存期間とは別に適用し，データの保存期間が無制限の場合も適用する．整理は取り込み時等に行い，選択中又は処理中の音声や，保存された中断情報等により再開に必要と判断される音声は保持する．本アプリの外で利用者が選んだ元のファイルは，この整理では削除しない．

6.　長い音声の文字起こしでは，続きから再開するため，認識した本文を含む途中の結果及び進行状況を端末内に保存する．これらは，文字起こしが完了して結果を保存できた後，同じ音声と設定で最初からやり直す場合，又は保存・更新から第5項の期間を過ぎた後の整理で削除する．完了結果を保存できなかった場合は，復旧のため途中の結果を残す．

7.　録音中は，途中で停止した場合にも音声を復旧できるよう，端末内に録音の途中のファイルを保存する．録音終了後に M4A へ変換し，保存及び必要な確認が済んだ後に途中のファイルを削除する．変換又は保存ができなかった場合は復旧用に残し，削除に失敗した場合も後に再び削除を試みる．

8.　ほかのアプリの共有からファイルを受け取る場合は，受け取り口に置かれたファイルの写しを端末内へ取り込み，取り込みが済んだ後に受け取り口の写しを削除する．取り込みに失敗した場合や，処理中・非対応の形式等のため受け付けない場合も，受け取った写しを削除する．削除に失敗した場合は利用者へ案内し，アプリを開いている間の再表示時に削除を再試行する．取り込んだ音声の写しには第5項を適用する．共有元のアプリが管理する元のファイルは，この削除の対象ではない．

9.　第4条第2項の機能を備えた版において，利用者が OpenAI の利用を選んだ場合は，使用量を確認するため，日付，用途，モデル，通信回数，失敗数，使用量が未取得又は一部のみの件数，トークン数及び音声時間等の集計を端末内に保存する．再試行及び接続テストも集計に含めるが，文字起こしの本文，音声及び API キーは含めない．この集計は動作の記録とは別に保存し，期限による自動削除や，アプリの画面からこの集計だけを削除する機能は設けていない．本アプリを端末から削除した場合は，端末内の集計も削除される．集計には iOS のファイル保護を適用し，バックアップから除外する．

4. 端末の外との通信

本アプリが端末の外と通信するのは，次の各項に掲げる場合に限る．

1.　次の各号に掲げる通信には，録音及び文字起こしの内容は含まれない．

一　アプリに同梱していない音声認識モデル等を利用者が選んだ場合のダウンロード（Hugging Face）

二　端末内音声認識に必要な資源のダウンロード（Apple．録音中のライブ文字起こしを含む）

三　App Store での購入，購入の復元及びオファーコードの引き換えの処理（OS の StoreKit が Apple と直接通信する．第5条）

四　外部サービスの接続テスト（利用者が実行した場合．モデルの一覧の取得と固定の短文による確認を行い，録音，文字起こしの本文及び辞書は送らない．外部サービスの少額の利用料が発生することがある）

2.　本アプリが外部の音声認識又は AI のサービス（OpenAI 等．以下「外部サービス」という．）を利用する機能を備える場合，その機能は，利用者が設定でその利用を選んだときに限り動作する．利用を選んだ場合は，選んだ機能の処理に必要な範囲で，次の各号に掲げるデータが，その外部サービス（OpenAI の場合は api.openai.com）へ送信される．API キーを保存する操作だけでは，送信は始まらない．

一　外部サービスで文字起こしをし，又は声により話す人を分ける場合の音声データ（分割したもの）．音声を送る利用範囲と外部サービスによる聞き直しを選んだ場合は，認識後にも該当区間の音声を再送信する．辞書に登録した語句を，認識の手がかりとして併せて送ることがある

二　録音中のライブ文字起こしに外部サービスを使う場合の録音中の音声

三　文字起こしの後の照合，話す人の判定等の文章処理に外部サービスを使う場合の文字起こしの本文，辞書に登録した語句及び声の高さ等の数値の特徴（この文章処理自体には音声を送らない．区間の聞き直しに伴う音声の再送信は第一号のとおりである）

3.　前項の送信は，利用者が選んだ利用の範囲（音声も送るか，文章だけを送るか等）及び機能ごとの設定に従う．送信の範囲と止め方は，本アプリの設定画面で確かめることができる．送信を止めるには，設定で外部サービスの利用をやめるか，API キーを削除すればよい．API キーは，外部サービスへの認証以外には使用されない．外部サービスへ送信されたデータの取扱いは，その外部サービスのプライバシーポリシー及び利用規約の定めるところによる．

4.　「iOS標準」方式の音声認識は，端末内の認識を使用する．端末外での処理を許す設定を備えた版において利用者がその設定を選んだ場合に限り，OS の音声認識機能が音声を Apple のサーバーで処理することがある．

5.　利用者が保存先又は共有の相手に iCloud Drive 等のクラウドを自ら選んだ場合は，その選んだ先へデータが複製される．また，ファイル App 又は写真から利用者が選んだファイル・ビデオがクラウド上にある場合，読み込みのために OS 又は提供元のサービスが通信し，そのデータを端末へ取得することがある．

6.　利用者が任意に OS の作文ツールを使用する場合，選んだ機能に応じて，文章や入力した指示が，Apple 又は ChatGPT（OpenAI）による処理のため端末の外へ送信されることがある．この機能は本アプリの API キーを使用せず，第2項及び第3項の設定とは別に動作する．作文ツール及び ChatGPT の利用の可否や送信時の確認は OS 側で管理され，送信された情報には利用するサービスのプライバシーポリシー及び利用条件が適用される．Apple の ChatGPT 拡張の説明も参照されたい．

7.　利用者が不具合報告又は問い合わせを送る場合は，利用者が選んだメール又は共有の方法により，第1条第3項の内容が開発者へ送られる．

8.　利用者が本アプリ内の外部リンクを開く場合は，ブラウザ等がリンク先のサイトと通信する．リンク先の閲覧に伴う情報の取扱いは，そのサイトのプライバシーポリシー等に従う．

9.　画面を閉じた後も文字起こしを続ける機能は，iOS の仕組みを用いて端末内の処理を継続するものである．この継続のために録音又は文字起こしの本文を外部へ送信するものではない．継続できる時間及び中断は iOS の制御に従う．

5. 購入

1.　本アプリが有料の機能（買い切り又はサブスクリプション）又は開発を応援するチップを提供する場合，その購入，支払い，更新，解約及び返金は，Apple の App Store の仕組みにより行われる．チップは任意のアプリ内課金であり，購入しても利用できる機能は変わらない．開発者は，利用者の氏名，支払い方法，カード番号その他の決済の情報を受け取らない．

2.　本アプリは，有料の機能を利用できるか，又はチップの購入が完了したかを確かめるため，OS の StoreKit を通じて，購入した品目，購入日，有効期限，取引の識別子等の購入の情報を，購入の種類に応じて取得し，端末内で使用する．これらの情報は，開発者のサーバーへ送信されない．

3.　App Store のオファーコード（特典のためのコード）を利用する場合，コードの引き換えは App Store で行われる．開発者は，コードを引き換えた利用者の氏名及び連絡先を受け取らない．

4.　開発者は，App Store Connect を通じて，Apple からダウンロード数，販売数，売上等の集計された情報を受け取る．これには，利用者個人を特定する情報は含まれない．

6. 端末の機能の利用目的

本アプリは，次の各号に掲げる目的のために端末の機能を利用する．許可を求める機能については，利用者が端末の設定において許可を変更することができる．

一　マイク　会話の録音と，そのライブ文字起こしのため

二　音声認識　音声を文字に変換するため（第4条第4項）

三　Face ID 等の生体認証　アプリロックのため．認証の情報は端末内で処理され，本アプリはこれを取得しない

四　通知　文字起こしの完了又は失敗，録音の停止，裏で続けている文字起こしの中断及び利用者の操作が必要な状態を，端末内の通知で知らせるため

五　写真　「写真のビデオから読み込む」で利用者が選んだビデオを読み込むため．選ばれたもの以外の写真及びビデオを本アプリが読み取ることはない

7. 第三者への提供

本アプリが開発者へ自動送信する利用者の情報はなく，開発者が利用者の情報を第三者へ提供することもない．第4条第2項の外部サービスへの送信は，利用者が自らその利用を選んだことに基づくものである．

8. 広告

現在の配布ビルドに広告は含まれていない．将来，広告を導入する場合も，興味関心に基づかない配信（非パーソナライズ）のみを使用し，録音・文字起こしの内容や辞書に登録した語句を広告事業者へ送ることはない．

本方針は日本語を正文とする．他の言語に翻訳して提供する場合において，日本語版と他の言語版との間に相違があるときは，日本語版の解釈が優先する．
