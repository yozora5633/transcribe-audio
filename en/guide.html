Before You Use Transcribe Audio

Last updated: October 6, 2026

1. About this document

1. This document is a guide summarizing matters we would like you to know when using Transcribe Audio (hereinafter "the App"). Matters in this document that concern a particular feature apply to versions of the App that have that feature.

2. This document is not a contract. Regarding the license for the App, if it was obtained through the App Store, the standard Licensed Application End User License Agreement established by Apple Inc. applies.

3. This document can be viewed on this page at any time.

2. Positioning of the App

1. The App is a tool that records Japanese conversations or imports audio files to create transcriptions.

2. Transcriptions are the result of machine processing using one or more speech recognition engines and language models, depending on the settings, and may contain errors. The degree of error varies depending on the recording conditions, manner of speech, specialized vocabulary, and other factors.

3. When using the App for purposes that require accuracy, please use the segment playback feature to compare against the original audio and verify the content yourself. The content of the final text, once verified, is left to the user's judgment.

3. Nature of recognition results

1. Speaker estimation is an inference made from voice characteristics and utterance content, and mix-ups can occur. It does not identify individuals in the way voiceprint authentication does.

2. Items shown as correction candidates merely present possible alternative readings. Whether to adopt them is determined by the user's action.

3. Words registered in the dictionary are used as clues for recognition, but this does not guarantee that the registered spelling will always be obtained.

4. About using external services

1. The App transcribes on the device. If the App has features that use an external speech recognition or AI service such as OpenAI (an "external service"), those features are used only when the user chooses to use them in Settings.

2. Features that use an external service’s API key can be used by the user contracting with the external service themselves, setting the key they obtained, and then choosing the usage scope and individual features. Merely saving the key does not start any transmission. API usage fees are settled between the user and the external service and are separate from the price of the App.

3. Data sent to external services is governed by the Privacy Policy. To stop transmission, stop using the external service in Settings or delete the key.

4. Please manage your key at your own responsibility. The key is stored only in the device's Keychain (encrypted area) and is not used for anything other than authentication with the external service.

5. An external service’s "Test Connection" checks availability by retrieving the list of models and sending a fixed short sentence. It does not send audio, transcription text, or the dictionary. A small API usage fee may be incurred, and it is not a balance inquiry.

6. Choose Refine with Writing Tools from the menu on the result screen to edit a draft separate from the original transcription. On supported configurations, you can use the OS’s Writing Tools and ChatGPT, then copy or save the refined text separately. This does not use the App’s API key or incur API charges. Free and signed-out use has limits; ChatGPT sets usage limits and paid-plan terms. Availability and transmission follow OS settings, separately from the App’s external service settings. See Apple’s setup instructions.

5. About purchases

1. If the App offers paid features (one-time purchases or subscriptions), their purchase, payment, renewal, cancellation, and refunds are governed by the App Store. The price and what is included are shown in the App and on the App Store before purchase.

2. A subscription renews automatically each period unless canceled. To cancel, go to Subscriptions under your Apple Account in the device’s Settings. After canceling, you can keep using it until the end of the period already paid for.

3. Purchased features can be used again on devices signed in with the same Apple Account by using Restore Purchases in the App.

4. App Store offer codes are redeemed on the App Store or from a screen in the App. The conditions and expiration of each code are as set for that code.

5. Refund requests follow Apple’s refund procedure. The developer cannot directly refund purchases made through the App Store.

6. Handling of data

1. Recordings, transcriptions, history, the dictionary, and all other data handled by the App are stored on the user's device. The developer cannot obtain or view them.

2. The preceding paragraph does not apply when the user sends data outside the device themselves via the share feature or other operations, or when the user chooses to use an external service.

3. How to delete data and the auto-delete settings are governed by the Privacy Policy.

2. The highest-quality multilingual Whisper model is included in the App. Using other models requires additional downloads, and the quality available may differ depending on the device's free space and performance.

3. Some or all features of the App may become unavailable due to changes in OS or external service specifications, or for other reasons.

4. The developer may change the content of the App, or suspend or terminate its provision.
