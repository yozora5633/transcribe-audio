About Transcribe Audio

Transcribe Audio is an iPhone / iPad app that records Japanese conversations, such as interviews and meetings, and transcribes them. By default, it transcribes on your device using the highest-quality Whisper model included with the app, showing text as it is recognized. Depending on your settings, you can also compare multiple recognition results and estimate speakers.

What you can do

Record on the spot or import an audio file, and a verbatim transcription is created. You can replay the original audio segment by segment and compare it as you edit the text.

Results can be exported as text and Markdown. Frequently used names and terms can be registered in the dictionary, which helps recognition.

How data is handled

Recordings, transcriptions, history, and the dictionary are all stored on your device. There is no developer server, and the developer never receives or sees the contents.

To use OpenAI transcription or speaker separation, enter your own API key and choose which data and features to allow. API charges apply separately. Turning off “Allow sending to OpenAI” or deleting the key stops the app’s OpenAI API transmissions. Optional Writing Tools follows OS settings separately. Apple server processing for iOS speech recognition and syncing to cloud storage follow separate settings.

The interface and documentation are available in Japanese and English. Audio processing is currently designed for Japanese; an English interface does not mean that every feature supports English audio.
