Transcribe Audio User Guide

Updated September 11, 2026

Start by recording or selecting an audio file. The default Whisper setup works without an API key, and the highest-quality model is included in the app.

1. Start a transcription

If settings feel complicated, tap Use On-Device on the home screen. This selects the highest-quality on-device transcription and stops sending to OpenAI. Choose a speaker count if needed; speaker labels use a separate on-device estimator. Your API key, recordings, and history are retained. Use OpenAI selects API-billed recognition after key setup. Then record or select an audio file. How to Use is also available on the home screen.

Record now

  1. Choose Record and Transcribe on the home screen.
  2. Start recording, then stop when finished.
  3. Choose Use This Recording to return home, then start transcription.

Use an existing recording

  1. Choose an audio file on the home screen using Files.
  2. Check the filename and start transcription. Download files stored in the cloud first.

Text shown while recording is a preview. Transcription after recording is a separate step. Keep the app in the foreground until it finishes.

2. Review, copy, and save

Read the full transcript and play the original audio in Segments. Use the pencil button to edit text or speaker names. A review marker indicates a possible error, not a confirmed mistake.

Use Copy & Save to copy, export, or share the text. Completed results can also be opened from History. Check important numbers, names, and negations against the original audio.

3. Choose a recognition method

The app includes an interactive choice guide under How to Use → FAQ → Which model should I use?

I do not want extra API charges

  • Whisper, highest quality: Use the default setup for on-device speech recognition.
  • iOS built-in: Uses Apple speech recognition. Depending on settings and availability, Apple servers may be used.

Adding OpenAI API features incurs separate API charges. Network charges depend on your connection plan.

I am willing to pay API charges

  • Use GPT-Transcribe for the transcript when speaker labels are unnecessary.
  • Use Diarize to obtain text, speaker labels, and utterance times from one model.
  • Combine GPT-Transcribe and Diarize to recognize the text with a separate model as well. Sending the same audio to both increases API costs.

Accuracy varies with recording conditions.

Compare results from multiple engines

When combining Whisper and iOS recognition, the app automatically compares their results. You do not need to add a separate processing step afterward.

With OpenAI transmission off, comparison takes place on-device. Supported devices can use Apple Intelligence; otherwise, text similarity is compared and alternative candidates are shown while retaining the base transcript. This is separate from the ChatGPT extension.

Processing takes longer, and accuracy is not guaranteed to improve. Check remaining differences against the original audio. Refining the text with Writing Tools is optional.

4. Separate speakers

Select one person with no speaker separation to omit labels. Auto estimates the count; selecting a count caps the number of speakers in the result. A selected count does not guarantee accurate identification.

Whisper itself only transcribes text and does not identify speakers. iOS speech recognition also does not return speaker identities; the app can add its own estimation. OpenAI offers Diarize for speaker separation. Similar voices and simultaneous speech can cause mistakes with any approach.

5. Where OpenAI is used and how to stop it

Allow sending to OpenAI changes transmission permission only. After adding a key, choose the recognition method and features you want. Usage and controls shows the enabled uses and their off buttons.

To stop all app API transmissions: Turn off Allow sending to OpenAI. This also cancels any transcription in progress, while retaining your key and other settings. OpenAI live display stops, but recording continues.

Whisper with one speaker can still use OpenAI for optional re-listening decisions or live text display while recording. These are separate settings from the speech recognition method.

Create an API key and add credit

  1. Check payment methods and credit terms in OpenAI billing.
  2. Create a key under API keys.
  3. Open API Key in the app’s settings, paste the key, and save it. Allow sending to OpenAI to use Test Connection and check access.

API fees are separate from the app price and ChatGPT plans. The connection test checks the model list and sends a fixed short sentence; it does not retrieve your balance. A small API fee may apply. Check spending and usage on OpenAI’s usage page.

Keys are encrypted in the iOS Keychain. The developer’s information site is static GitHub Pages content with no API-key submission form or receiving service. The app does not send your key to the developer. See the Privacy Policy.

6. Refine text with Writing Tools

Choose Copy & Save → Refine with Writing Tools to open a separate draft. Your original transcript stays unchanged. Copy or save the refined draft separately.

Writing Tools and ChatGPT may be available depending on your device and OS settings. This feature does not use the app’s API key or incur API charges. Free and signed-out use has limits; ChatGPT sets usage limits and paid-plan terms.

Writing Tools transmission follows OS settings, separately from the app’s OpenAI permission. See Apple’s instructions.

7. Manage recordings, history, and settings

Recordings are stored under Transcribe Audio/Recordings in Files. Selecting another destination creates an additional copy. Deleting a history entry removes its transcript, not the original recording. Manage recordings and destination copies separately.

Open Settings → Recording and Data Storage to change retention and app lock. New installations use 90-day retention. Existing data follows the choice made during migration. Copies in other folders are outside automatic deletion. Read the deletion confirmation before shortening retention.

Closing the current audio returns home to its initial state. Resetting transcription settings restores highest-quality Whisper, no speaker separation, and no OpenAI use. Neither action deletes saved data. Resetting also retains your key, dictionaries, retention, and app lock.

8. Frequently asked questions

Do I need a manual extra step with Whisper plus iOS recognition?

No. Comparison is automatic. Check remaining differences against the original audio. Writing Tools is optional. Choose a method

Why is OpenAI used with Whisper and one speaker?

Optional re-listening decisions or live display may still be enabled. See Usage and controls.

Can I work completely offline?

Use On Device transcribes with the included highest-quality Whisper model. Preparing Apple models for live text during recording, or downloading and syncing cloud files, may require a connection.

Why can’t I start recording?

Check microphone permission and available storage. Follow any settings link shown on the recording screen.

Which audio files and lengths are supported?

Import one audio file at a time. The app uses formats that iPhone can read and convert. If import fails, export another audio format from the original app. Split audio longer than four hours before using Whisper.

Can I lock the screen or switch apps?

Recording can continue while locked, but calls and OS restrictions may interrupt it. Keep the app foregrounded during subsequent transcription. If a resume prompt appears, use the same audio and settings to reuse saved work. Unfinished parts may need to be processed again.

Why does unexpected English or strange text appear?

It may be a recognition error, but it can also be an actual English word or name. The app does not automatically delete it. Listen and edit.

Why does the connection test fail when I have credit?

Key permissions, model access, and temporary restrictions can also cause errors. Open the error details. Never include your API key in a support request. OpenAI setup

Can I use English?

Display Language in Settings opens the iOS per-app language setting. Display language and audio language are separate. Current audio processing is designed for Japanese; not every processing path supports English audio.

Does deleting history also delete the recording?

No. Original recordings and copies in other folders remain. Manage each separately. Manage data
